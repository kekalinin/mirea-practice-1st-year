В рамках прохождения ознакомительной практики был проведен анализ нескольких моделей машинного обучения на задаче прогнозирования цен на недвижимость (как классической задаче регрессии).
В итоге сформирован вывод, согласно которому из трёх протестированных моделей лучшей по всем метрикам качества безоговорочно признаётся Random Forest. Он обеспечивает
как наиболее точные, так и максимально устойчивые прогнозы на исследуемой выборке. В то же время линейная регрессия оказалась непригодной для данной
задачи, поскольку данные носят нелинейный характер. Модель дерева решений показала достаточно хорошие результаты, однако по итоговой точности всё же
уступает ансамблевому методу случайного лесу.
